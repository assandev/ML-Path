# ML/AI Engineer Path

Notes and resources from the [Codecademy ML/AI Engineer Career Path](https://www.codecademy.com/enrolled/paths/machine-learning-engineer).

## Topics

### Data Transformation
Techniques for preprocessing numerical features before feeding them into ML models:
- Data Centering
- Standardization (Z-Score Normalization)
- Min-Max Normalization
- Binning
- Natural Log Transformation

### Feature Engineering
Strategies for selecting and creating features that improve model quality, evaluated across four attributes: performance, runtime, interpretability, and generalizability.

### Supervised Learning
Learning from labeled data to make predictions:
- **Regression** — predicting continuous values (e.g. housing prices)
- **Classification** — predicting discrete categories (e.g. spam detection)
- K-Nearest Neighbors (KNN)

### Unsupervised Learning
Discovering patterns in unlabeled data:
- Clustering
- K-Means algorithm

## Repository Structure

```
.
```
